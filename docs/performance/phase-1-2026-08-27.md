# Phase 1 renderer performance results

- Date: 2026-08-27
- Benchmark revision: `7eff1f3`
- Profile: Cargo release
- Machine: MacBook Pro `Mac16,1`, Apple M4, 10 cores, 16 GB memory
- Operating system: macOS 26.5.2, build 25F84
- Rust: 1.95.0
- Node.js: 26.0.0
- Renderer: MathJax worker 0.1.0 with MathJax 4.1.3

Command:

```sh
cargo run --release -p latex-bench
```

Results:

| Metric | Samples | Measured | Target | Result |
|---|---:|---:|---:|---|
| First render including worker startup | 1 | 239.161 ms | ≤ 1500 ms | Pass |
| Warm uncached simple render p95 | 60 | 1.831 ms | ≤ 150 ms | Pass |
| Warm complex render p95 | 30 | 8.253 ms | ≤ 500 ms | Pass |
| Cached render lookup p95 | 1000 | 0.002 ms | ≤ 10 ms | Pass |
| Segmenter delta p95 | 10000 | 0.001 ms | ≤ 5 ms | Pass |

The first metric includes process creation, protocol handshake, MathJax readiness,
and one simple render, so it is a conservative check of the readiness target. The
warm simple p95 exit criterion passed with substantial margin.

This run does not measure resident memory. The 150 MiB memory target remains a Phase
4 packaging and sustained-session measurement rather than a Phase 1 exit criterion.

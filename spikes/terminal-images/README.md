# Terminal image feasibility fixture

The checked fixture is generated by the pinned MathJax worker, then rasterized
with the macOS Quick Look renderer for the Phase 0 terminal experiment. Quick
Look is not part of the production architecture. The production rasterizer will
be local, cross-platform, bounded, and covered by the renderer conformance suite.

Generate the SVG after building the worker:

```sh
corepack pnpm --dir renderer/mathjax-worker build
node spikes/terminal-images/generate_fixture.mjs
```

Generate the temporary macOS PNG:

```sh
qlmanage -t -s 1024 -o fixtures/terminal fixtures/terminal/quadratic-formula.svg
ffmpeg -i fixtures/terminal/quadratic-formula.svg.png \
  -vf crop=1024:192:0:0 -frames:v 1 fixtures/terminal/quadratic-formula.png
```

The cropped `quadratic-formula.png` is the input to the Rust terminal spike.
The intermediate Quick Look thumbnail is disposable. Both checked source assets
remain deterministic inputs for the protocol test; visual quality decisions do
not depend on the Quick Look output.
